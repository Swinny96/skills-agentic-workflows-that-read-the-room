## Recent GitHub Blog and Changelog stories worth watching

- **Enterprise managed permissions for GitHub Copilot agent operations** (GitHub Changelog, Sep 9, 2026) — Admins can now centrally control which Copilot agent operations (shell, file, and network access) are blocked, require approval, or auto-proceed, consistently across the Copilot app, CLI, and VS Code Agent Host.
- **Remediate Code Quality findings with agentic autofix** (GitHub Changelog, Sep 9, 2026) — Developers can select up to 25 code-quality findings at once and assign them to Copilot, which fixes them on a branch and opens a pull request.
- **GPT-6 Astra generally available in GitHub Copilot** (GitHub Changelog, Sep 4, 2026) — A new model built for long-horizon autonomous coding tasks is now GA across Copilot.
- **GitHub Actions: Early September 2026 updates** (GitHub Changelog, Sep 3, 2026) — Adds a REST API for runner-version deprecations and a new `vulnerability-alerts` `GITHUB_TOKEN` permission for workflows.
- **GitHub Copilot app for Beginners: Run several agents at once** (GitHub Blog, Sep 3, 2026) — A how-to guide covering running parallel Copilot agent sessions from the Copilot app.
- **Decoding the new AI lingo: Loops, harnesses, squads, hill climbing... oh my!** (GitHub Blog, Sep 2, 2026) — A podcast episode unpacking emerging AI-assisted development terminology for developers new to agentic coding.

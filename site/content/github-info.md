## Recent updates worth watching

- **Copilot code review can now approve pull requests.** Copilot reviews now include an approval assessment, and admins can opt in to let Copilot sign off on pull requests at the enterprise, org, or repo level (public preview). (GitHub Changelog, September 1, 2026)
- **GitHub CLI can attach images and videos.** The `gh` CLI's repeatable `--attach` flag uploads local media and references it inline in issues, pull requests, and comments, generally available with `gh` v2.99.0+. (GitHub Changelog, September 1, 2026)
- **Refreshed repository pull requests page in public preview.** A new pull request listing page adds content-assist filtering, AND/OR advanced search, a collapsible sidebar, and a compact presentation mode. (GitHub Changelog, September 10, 2026)
- **Agentic workflows automate repository tasks with Copilot.** These are markdown files that combine YAML frontmatter (triggers, permissions, safe outputs) with natural-language instructions, compiled via the `gh aw` CLI and run by the Copilot coding agent in GitHub Actions — useful for scheduled reports, issue triage, and event-driven automation. (Awesome Copilot Learning Hub, "Agentic Workflows")
- **How canvases make agentic workflows visible, steerable, and cost-efficient.** A look at how GitHub Copilot canvases help developers monitor and guide autonomous agent work. (GitHub Blog, AI & ML)
